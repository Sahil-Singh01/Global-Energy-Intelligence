# Project reports

This folder contains the written documentation that complements the analysis notebooks.

| Document | Purpose |
|---|---|
| [Executive summary](executive_summary.md) | Dataset overview, main observations, statistical result, and limitations |
| [Project methodology](project_methodology.md) | Workflow, entity rules, missing-data decisions, statistical design, and reproducibility |
| [Data-quality report](data_quality_report.md) | Integrity checks, missingness, entity coverage, and recommended actions |
| [Statistical findings](statistical_findings.md) | Detailed interpretation of the renewable-share/carbon-intensity analysis |
| [Data dictionary](data_dictionary.csv) | Column inventory, inferred variable families, types, and missingness |

The CSV tables and figures generated by the notebooks are stored separately under [outputs](../outputs/README.md). Run the notebooks from the repository root to regenerate them.
